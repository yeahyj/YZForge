# 框架优化与面板改造复核

2026-09-22，实施位置 `E:\study\YZForge`。本轮落实方案审查后的核心改进；调用示例见 [API 指南](api-guide.md)，实测证据见 [实施记录](implementation-status.md)。

## 核心决定与结果

| 范围         | 改造结果                                                                              | 保留的边界                                                     |
| ------------ | ------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 生命周期权限 | `show/activation/ctx.scope` 为稳定、冻结的 `Lifetime` 门面；自己的 child 才有关闭权限 | 普通 TypeScript API 约束，不是隔离不可信代码的沙箱             |
| 异步操作     | Actions 提供 latest、exclusive、有界 serial；UI 与 Part 共用实现                      | 只处理交付与使用期，不能撤销支付、发奖等已经发生的业务效果     |
| UI 与 Part   | 激活期统一提供 assets/config/audio/time/actions；绑定检查 Cocos 对象有效性            | UI 展示、实例缓存与 Part 激活仍有不同生命周期，不强行合并      |
| 模块 API     | 方法进入前登记返回链；最后持有者退出后先等调用完成，再释放服务                        | 不自动跟踪脱离返回链的任务，不代理返回的所有嵌套对象           |
| 批量配置     | 首个错误立即取消本批等待，其他调用方的共享加载继续                                    | 分片显式选包，不偷偷合并；共享数据保持只读                     |
| 配置释放     | 最后一个已交付持有者等待异步清理                                                      | 取消尚未完成的底层加载不代表网络请求被物理终止；迟到结果会归还 |
| 启动         | App 构造失败清理部分服务；BootFlow 为每次尝试建立独立期限，可显式重试                 | 不自动重试副作用，不用超时强行销毁仍在执行的工作               |
| 模块声明     | `module.json.dependencies` 为别名映射，生成类型引用和运行时装配                       | 删除重复手写映射；生成文件不由业务手工编辑                     |
| 资源模块     | `code.mode: none` 不生成空业务工厂；common 已迁移                                     | 不允许声明业务依赖、UI 或 Part 注册                            |
| 可选账户隔离 | `Storage.in(namespace)` 隔离同键数据和备份                                            | 不引入强制账号、登录或网络框架                                 |
| 失败恢复     | 创建保留原始前后快照；生成写入有独立日志、预览和恢复入口                              | 不宣称 AssetDB、普通文件、XLSX 为一个全局原子事务              |

## 工作台

- 采用侧栏导航、当前模块区域、职责卡片和折叠操作详情；窄窗口自动转为横向导航与单列卡片。
- 名称变更后延迟 450ms 自动预览，列出脚本、预制体、目录、元数据与生成文件。过期预览不会解锁创建按钮。
- 创建、保存、删除、恢复期间暂时锁定输入，提交的快照保持可见。输入事件同步读取表单，避免快速切换模块时把草稿写到别处。
- 模块与工作簿草稿切换后仍保留；未保存状态可见。刷新不会抹掉尚未保存的设置。
- 没有工作簿、绑定对象或恢复记录时给出下一步说明，相应操作禁用。
- 日历用固定 UTC 偏移选项和 `HH:mm` 时间选择；不要求开发者计算刷新分钟数。已有非标准偏移仍保留可选。
- 纯资源模块不提供业务依赖候选；创建代码与界面时在预览阶段说明原因。
- 删除展示实际文件和外部引用；创建失败与生成中断分别恢复。新设计没有章节、关卡或特定游戏类型入口。

## 恢复语义

创建日志 `.yzforge/creations` 的完成快照不会被后续生成重试改写。用户编辑与工具修改不会因为一次失败重试被混为一体。已有引用或新文件阻止撤销；引擎资产通过 AssetDB 处理。

生成日志 `.yzforge/changes` 保存普通生成文件的不可变旧内容和目标内容。写入前再检查旧内容，写回后再核验；失败尽量回滚自己的变化，冲突保留。下一次生成会拒绝未完成日志，要求先在面板预览恢复。

恢复重新检查签名和当前文件。当前内容既不是旧内容也不是工具输出时，拒绝覆盖。活跃生成进程持有的锁不会被删除；进程已消失时才能收回陈旧生成锁。若恢复自身再次被强杀，可能需要检查 `.yzforge/recovery.lock`；不会凭超时猜测锁可以删除。逐文件恢复中再次中断，可基于剩余差异重新预览。创建尚无完整后快照的硬崩溃仍需检查残留并走正常删除流程。

## 本轮复核发现并修复

1. 生成重试重拍创建快照，可能使撤销覆盖用户编辑：改为保持原快照，增加失败重试回归。
2. 模块方法只验证入口，异步执行中可能销毁 Service：调用前登记返回链，清理等待物理完成。
3. 批量配置用 allSettled，已知失败仍被未完成请求拖住：改为首错取消本批等待。
4. 配置底层释放采用游离 Promise：最后持有者归还时等待异步清理。
5. 面板依赖预览已归一化为对象，创建阶段还当作数组：支持预览往返并保留别名，增加回归测试。
6. 表单事件延后读值，快速切换导致草稿归属错误：同步读取当前表单，继续异步处理结果。

没有把 Bundle 元数据缓存一概当成内存泄漏，也没有加入强制卸包、通用重试、全局事务或服务容器。原生真机、微信开发者工具及真机行为仍需要对应环境验收；本轮验证覆盖 Creator、Web 运行及微信构建产物。
