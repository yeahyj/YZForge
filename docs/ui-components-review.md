# 通用 UI 组件审查

审查日期：2026-09-23。范围为 SafeWidget、AsyncButton、AsyncSprite、ViewState、CountdownLabel、TabGroup、共同的生命周期适配、业务示例、自动绑定、预制体、中文 API 和文档。

## 易用性

默认路径以 Inspector 为入口：组件位于“YZForge → UI”菜单，主要属性、枚举和说明使用中文。SafeWidget 自动补齐 Widget/UITransform；按钮自动防连点；图片配置资源名及占位/失败图；四态配置节点和事件；倒计时配置秒数、格式和完成事件；页签直接拖 Toggle 与内容节点。

除 SafeWidget 外复用 GameComponent 的自动注入和激活期，不另造场景扫描器或全局单例。示例的换图、四态、倒计时、普通页签不写 bind。静态图片继续使用原生 Sprite；AsyncSprite 仅用于动态资源。显式 bind 保留为列表复用、自定义期限和动态内容的高级接口。

## 已修复与复审内容

1. **快速切换绕过清理。** A→B→C 中 B 尚未开始就被取消时，C 可能越过 A 的清理。等待屏障独立登记到 Scope，未启动的 B 也能传递 A 的屏障。
2. **页签业务错误变成取消。** 失败后先 close 会抢先交付 OperationCancelled。现在先登记原始结果交付，再清理失败内容；测试验证原错误及再次重试。
3. **点击当前 Toggle 取消高亮。** 当前内容还在，但原生 allowSwitchOff 会让按钮不选中。有效选择期间保持至少一个选中，清空状态时临时允许全不选，解绑恢复原值。
4. **无效 owner 破坏旧按钮绑定。** 在清理旧绑定前检查取消状态，失败的 bind 不影响已有按钮。
5. **禁用后重新启用期间触发按钮。** GameComponent 仍在等待旧任务时，run 返回 false；旧任务及异步清理结束才恢复新激活期，禁止迟到 commit。
6. **销毁期间解绑依赖已销毁组件。** 按钮绑定捕获节点引用，避免在销毁回调中重新经已销毁 Button 取 node；外部时间、窗口及节点监听由所属期限移除。
7. **安全区依赖声明覆盖。** 使用单个 `requireComponent([Widget, UITransform])`，实际引擎验证直接挂载时两个依赖均补齐。

Scope 关闭屏障、旧句柄隔离、占位图资源归属、四态反复重试、计时回拨去重、静态/动态页签两种模式切换、安全区坐标换算均已复审。当前验证范围内未发现未修复的阻塞问题。

## 验证边界

实际运行验证为 Creator 3.8.8 浏览器预览，未声明微信或原生真机通过。SafeWidget 支持同一正交 Canvas 的轴对齐、正缩放固定布局；旋转、翻转、跨 Canvas 和透视相机明确拒绝。Inspector 事件遵循 Cocos 同步回调约定，异步业务使用 run 或高级 bind。业务任务需要响应取消，不配合退出的 Promise 仍会阻塞完整排空。普通页签保留节点，动态页签才采用离开销毁策略。
