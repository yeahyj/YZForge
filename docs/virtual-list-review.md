# 虚拟列表实现审查

审查日期：2026-09-22。范围包含框架组件、固定布局计算、复用调度、业务示例、自动绑定产物、预制体引用、单元测试与 Cocos 预览集成测试。审查后未发现尚未修复的阻塞问题。

## 审查中修复的问题

1. **异步绑定清理与预制体销毁次序。** Scope 已能递归等待后代任务，但兄弟 Scope 的异步清理回调可能与资源销毁并行。现在先把完整退场屏障登记到实例父 Scope，再取消绑定、失活 Part，最后才允许销毁资源。添加了先失败后通过的回归测试，以及真实 Cocos 节点有效性检查；取消监听重入 dispose 也纳入验证。
2. **网格切换后子 Widget 尺寸滞后。** Creator 的 `ON_WINDOW_RESIZE` 不会因为复用节点根尺寸变化自动重新对齐。现在仅在条目尺寸改变时更新启用的子 Widget。真实预览验证 200 宽条目的标题从 596 收缩到 172，且截图中的标签不再跨列。
3. **异步输入测试的观察时机。** show.listen 会调度回调，测试需等回调启动后再等待列表 whenIdle；截图还需等待实际绘制帧。集成测试已按这个时序验证清空和重排，避免把上一帧或尚未开始的操作当结果。

## 核心结论

- 每次绑定拥有新的 item.scope。刷新、滚出、替换数据和关闭都会同步取消旧上下文；订阅随取消退订，旧 commit 不再写节点。
- 复用同时等待绑定任务/清理与真实 Part 激活任务退出。异步 render 迟到不会再次激活旧数据；清理失败的节点销毁，不回到池中。
- 加载中滚动采用最新窗口，实例总量受视口容量约束。反复刷新后 Scope 子级数量稳定，父级关闭后实例与订阅清空。
- 业务预制体与 Part 保留在 showcase 模块。框架目录不依赖业务模块，自动绑定沿用工作台生成与序列化写入流程。
- 修改预制体通过当前 Cocos MCP、场景对象 API、Creator 序列化与 AssetDB 完成；既有 UiLabPage 的 122 个预制体对象 fileId 全部保留，只增加入口按钮及自动绑定字段（13 → 14）。
