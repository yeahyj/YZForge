## 通用性审查与修正

| 问题                                           | 已采取的修正                                                                              |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 工作台把资源包称为章节包，默认模板暗含某类游戏 | 改为模块、资源包、配置分片；设计规格中的通用规则也移除了章节前提                          |
| 模块必须创建资源包                             | 支持 `bundles: {}` 的纯代码模块，之后按需添加默认包或附加包                               |
| 创建 UI 固定竖屏尺寸及默认包                   | 读取 Creator 项目设计分辨率，可选择模块内已声明的目标资源包                               |
| UI 模板预设标题等业务参数                      | 初始 Params/Result 为 void；生成 ViewKey 自动关联业务定义的类型                           |
| 框架固定应用存档前缀                           | App 必须传入稳定 appId，使用独立的本地存储命名空间                                        |
| 时间、音频和绑定规则成为固定项目假设           | 项目设置维护音频分组、日历边界、节点前缀及平台计时单位，并生成运行时选项                  |
| 演示与通用工具混在一起                         | 演示在 assets/game，演示制作和验证脚本在 tests/integration；源码检查阻止框架反向导入 game |
| 模块编辑复用创建表单，容易误清空已有依赖       | 独立编辑字段，选择模块时回填显示名称和依赖                                                |

框架核心不包含大厅、战斗、金币、奖励、章节或关卡规则。当前 lobby、奖励弹窗、道具表与竖屏首屏均为可替换演示。设计中的此类代码只说明调用方式。

`extensions/yzforge-editor` 是 Creator 编辑器插件，不是运行时 Extension 系统。附加资源直接使用普通 Bundle；没有独立 ContentPack 注册、类型或生命周期，也未预建 libraries 扩展体系。

### 验证中修复的问题

- Creator 构建转换对 Map/Set 迭代器展开产生错误，预览却可通过：运行时改用 Array.from，加入源码检查，并重新构建运行。
- UI 自持有、清理回调未撤销、页面切换等待自身任务：调整使用期限与关闭顺序，补充真实预览检查。
- 清理超时提前回收的风险：逻辑超时返回失败并隔离实例，资源保留到任务实际排空。
- 音频竞态：旧请求不能覆盖后来 BGM，关闭时取消在途请求，归还声源前清空 clip。
- 图集帧仅持有帧的风险：同时持有所属图集与帧，验证共同释放。
- 导表约束拼写/类型不匹配及旧文件回收：显式报错，写入前检查手写引用，处理 Creator 空资产用户条目。
- 微信适配层 Date.now 性能计时别名：不把它视为单调时钟，提供 wx.getPerformance 适配与显式单位配置。

## 复现入口

```text
npm ci
npm test
npm run typecheck
npm run check
node tests/integration/verify-workbench.mjs
node tests/integration/verify-preview.mjs
```

工作台集成需开启本项目 Creator 与 MCP；预览集成需先运行 Bootstrap.scene 的 Game View。工作台测试会创建、回收临时内容。构建发布使用 Bootstrap.scene 为起始场景。

验证 Web 输出时，先运行 `node tests/integration/serve-build.mjs`，再将返回的本机 URL 传给 `node tests/integration/verify-build.mjs <URL>`。测试浏览器检查结束后自动关闭；HTTP 服务由启动者停止。
