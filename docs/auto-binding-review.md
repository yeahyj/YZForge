# 自动绑定增强审查

审查日期：2026-09-23。范围包括节点扫描、真实类型解析、Page/Popup/Part 生成、编译等待、预制体写回、中文文档和通用组件示例。复审发现并修复下述两项问题，当前范围未发现未修复的阻塞问题。

## 复审修复

- 类型解析原来会把任意类装饰器中的同名字符串当成注册名。已用表达式 ccclass 与另一个类的同名 menu 复现错误选类；现在只识别 ccclass，并支持解构、属性访问和变量别名。
- 界面和 Part 更新绑定原来没有检查未保存的编辑状态。现在扫描前及写回预制体前都检查；用户在编译等待期间继续编辑时也会停止写回，避免用已保存资产覆盖未保存的节点修改。

## 核对结果

- **选择规则**：按用户要求，同节点多个匹配组件固定取 Inspector 顺序中的第一个。原生前缀按继承关系过滤；Component 前缀跳过内置组件；Node 前缀保留节点引用。
- **实际类型**：通过 Creator 类标识、AssetDB 和 TypeScript 导出信息解析；支持原生子类、普通自定义组件、默认/命名/别名导出、中文类名。重复类型去重，同名类和关键字自动分配合法导入别名。
- **模块依赖**：具体类型用 type-only 导入，编译后不保留运行时导入；装饰器继续使用引擎基础类型，实际序列化引用仍是原组件。没有新增业务模块的提前加载路径。
- **编译与失败处理**：写回前核对本次编译签名、扫描结构和序列化字段。源码无法定位、未导出或结构变化时停止；未通过检查前不清空原有引用。替换组件但字段名相同时，也会等待正确的生成版本。
- **预制体边界**：包含非激活节点；嵌套预制体只访问根节点。组件示例仅改三个节点前缀及其引用，274 个节点/组件 fileId 全部保留。预制体通过 Cocos MCP 和 Creator AssetDB 更新。
- **生命周期**：自动绑定只生成类型和写入引用，不额外创建实例、监听、Scope 或异步任务。真实预览中的关闭、复用、取消、迟到回写和资源释放保持正常。
