# 功能展示与验证入口

打开 `assets/game/boot/Bootstrap.scene` 预览。首页提供八个入口；列表可滚动，左上角返回，底部“观察结果”显示操作结果。三种展示共用同一份实际实现。

## 可交互演示

| 入口             | 可以实际操作什么                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------- |
| 正式业务流程     | 完成训练、确认或取消领取、注入一次失败再重试、返回再进入；观察 Service / Presenter / Page / Part 分工               |
| UI 与 Part       | Page、Popup、Overlay、Toast、Loading，参数与结果、缓存、重复打开拒绝、Part 创建和提前释放、压栈与恢复               |
| 资源、配置与音频 | 静态预制体引用、动态 Key、重名候选、默认包与 extra 分片、跨模块表、批量读取、循环播放/暂停/继续/停止、通道音量      |
| 时间与日历       | 应用实时日期、独立模拟时钟、日/周/月/年边界、一周后、月末锚点、绝对截止时间、后台合并补发、回拨去重、模拟服务器校时 |
| 并发与恢复       | latest、exclusive、serial、失败重试、取消后等待实际退出、批量配置失败回收、独立 BootFlow 重试、离开时拦截旧 UI 回写 |
| 存档与隔离       | 独立内存实验中的保存读取、账号隔离、损坏恢复、写入失败、存档版本升级、高版本拒绝覆盖                                |
| 开发步骤         | 逐步解释真实文件职责，可再进入任务业务示例                                                                          |
| 综合示例         | 原大厅的公共配置、动态头像、弹窗、余额 Part、音效和日历通知；增加返回入口                                           |

时间实验中的“服务器”、异步实验中的“请求”是明确标注的模拟。实际调用框架服务，只替换其输入或适配器。任务奖励使用平台本地存档；存档故障实验使用独立内存，避免损坏任务示例的数据。

初始首页只创建 showcase 业务。先去资源页读取任务表，应看到任务代码与业务均未启动；再进入任务页面，才加载按需代码并创建业务。返回后业务可以释放，代码加载状态仍可能为 true，这属于引擎代码缓存。

## 红点、网络与聚焦引导

“UI 与 Part”增加两个子页面：网络页可以体验模拟成功/503/超时/取消，也能连接本机 HTTP 服务；引导页依次展示圆形聚焦训练按钮、连续变形成虚拟列表第 21 项矩形、真实点击领取、完成持久化和跳过。进入引导或换步时不会铺白屏，滚动等待和变形期间保持遮罩并锁定底层输入。

任务业务页和虚拟列表页加入红点：前者跟随可领取状态，后者展示一万条数据中的 100 个红点来源、合计与批量更新。来源随业务有效期存在，显示订阅随 show / activation / item.scope 结束。

完整操作见 [红点](badges.md)、[网络](network.md)、[新手引导](guide.md)。开启 Creator 浏览器预览后，可运行：

```sh
node tests/integration/verify-network-guide.mjs http://127.0.0.1:7456/
```

脚本通过当前 MCP 创建独立隐藏预览窗口和随机端口本机 HTTP 服务，验证红点、真实 XHR、物理输入、连续变形、恢复与清理；结束恢复预览设备选项并销毁自建窗口。提供的 URL 必须是当前项目的本机预览或构建运行地址。

## 通用组件

“UI 与 Part → 通用组件”展示 SafeWidget、继承原生控件的 AsyncButton/AsyncSprite/CountdownLabel、Switch 和 MarqueeLabel。可以连点提交、快速换图、按名字切换子节点、重启倒计时、切换长短文本观察自动滚动，以及模拟安全区。滚动页面可看到全部内容；换图、切换和计时等由 Inspector 事件驱动，完整接口见 [通用 UI 组件](ui-components.md)。

```sh
node tests/integration/verify-ui-components.mjs http://127.0.0.1:7456/
```

脚本使用当前 MCP 和独立隐藏窗口，验证重绑竞态、禁用/关闭清理、真实资源持有、Switch、滚动文本、倒计时校时与前台恢复，以及安全区百分比、缩放、嵌套和横竖屏。结束恢复设备和方向选项并关闭自建窗口。

## 编辑器工作流

**YZForge → 项目工作台 → 示例工作流** 提供七个步骤、十份源码的只读查看、任务表与绑定页跳转。完整说明在 [正式开发工作流](development-workflow.md)。

工作台原有“创建内容”先预览后生成；“自动绑定”扫描真实预制体；“配置表”选择目标 Bundle、校验和重算；“删除与恢复”先检查引用，再备份和执行。删除示例后，阅读入口明确提示文件不存在，其余通用工作台照常使用。

## 可控失败与自动验证

- `npm run test:showcase`：业务规则、写入失败一致性、领取去重、Presenter 确认/取消、跨模块状态刷新、订阅失败与结束后的解绑、模拟时间回收、存档故障。
- `tests/integration/verify-showcase.mjs`：在真实 Cocos 运行时检查任务流程、导航、UI 结果、缓存、分包、资源持有、失败恢复及多屏适配，包含慢加载下的真实鼠标输入。
- `tests/integration/verify-showcase-editor.mjs`：真实 Creator 工作台的步骤、源码读取和表格/绑定跳转。
- `npm run verify`：通用框架的静态检查、生成一致性与回归测试；与可删除的示例业务测试分开。

脚本前置条件和完整入口见 [实现范围与验证](implementation-status.md)。远程 CDN、真实服务器校时、账号认证、原生 SDK 和目标平台音频策略需要项目接入后实测。

## 示例的清理边界

示例模块为 `showcase`、`workshop`、`lobby`、`profile`、`common`；框架代码和工作台不依赖它们。`app/start-game.ts` 打开公开首屏，模块页面通过 `show.ui` 跳转。清理示例时解除启动调用，再删除示例模块，保留启动入口及应用装配。完整顺序与保留内容见 [复制项目与清理示例](copy-project.md)。
